# 🎱 Волшебный бильярд

Математический бильярд: полторы тысячи шариков вылетают из одной точки и отскакивают от бортика без трения, как луч света от зеркала. Шарики раскрашены радугой по направлению вылета и оставляют за собой гаснущие следы.

- **Столы:** ⚪ круг, 🥚 овал (эллипс, его фокусы отмечены белыми точками), 🏟️ стадион (две полуокружности и прямые между ними), ❤️ сердце.
- **Веер** — узкий пучок шариков в случайную сторону, **Звезда** — во все стороны.
- **Нажатие на стол** — шарики вылетают из этой точки; 🔄 — запустить ещё раз из той же точки, ⏸ (или пробел) — пауза.

Что увидеть:

- В овале «звезда» из фокуса после удара о бортик снова собирается в точку — во втором фокусе.
- В круге узкий веер долго летит дружной стайкой, а на стадионе и в сердце за несколько ударов рассыпается по всему столу. Это хаос.

Каждый стол — кривая `f(x, y) = 0`: шарик, вышедший за неё, возвращается на бортик (точка ищется делением отрезка пополам) и отражается от нормали `grad f`. Код — [billiard.ts](../physics/game/src/billiard.ts).

Урок работает на общем движке [physics](../physics). Здесь только настройки:

| Файл | Что это |
|---|---|
| `lesson.json` | название, иконка, раздел на главной и команда сборки |
| `scene.json` | какая сцена (`billiard`), строчка-загадка и текст карточки «Что тут происходит?» |

## Собрать и посмотреть

```bash
(cd ../physics/game && npm install)                 # один раз — TypeScript
node ../physics/game/build_scripts/build.mjs .      # → build/
open build/index.html                               # открывается и двойным кликом, без сервера
```
