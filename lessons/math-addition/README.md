# ➕ Сложение

Тренажёр на сложение: складываем числа от 0 до 9 — `3 + 4`, `9 + 8`, `0 + 5`. Всего 100 примеров, ответ — от 0 до 18.

В тетрадных клеточках — пример, внизу четыре ответа: один верный, три похожих на правду. На ответ — 3 секунды, посчитать на пальцах или калькуляторе не успеть: ответ надо знать. В раунде 20 примеров; сверху — сколько верно, сколько ошибок и среднее время верного ответа.

Урок работает на общем движке [math-drill](../math-drill) — там описано, как устроена игра. Здесь только настройки:

| Файл | Что это |
|---|---|
| `lesson.json` | название, иконка, раздел на главной и команда сборки |
| `drill.json` | действие, числа, секунды на пример, примеров в раунде — поля описаны в [math-drill/README.md](../math-drill/README.md) |

## Собрать и посмотреть

```bash
(cd ../math-drill/game && npm install)              # один раз — TypeScript
node ../math-drill/game/build_scripts/build.mjs .   # → build/
open build/index.html                               # открывается и двойным кликом, без сервера
```

Хотите 5 секунд вместо 3 или 30 примеров в раунде — поменяйте `seconds` и `count` в `drill.json`.
