# 🔎 Уравнения с дробями

Найди x: вместо первого или второго числа стоит x — `x + 1/3 = 5/6`, `2/3 × x = 1/3`, `x ÷ 3/4 = 2/3`. Все четыре действия вперемешку.

Каждый пример даёт два уравнения: `1/2 + 1/3 = 5/6` → `x + 1/3 = 5/6` и `1/2 + x = 5/6`. У каждого ровно один ответ. Неверные ответы — переписанное из уравнения число или обратное действие не тем знаком.

Уровень N здесь — уровни N уроков [сложения](../fractions-addition), [вычитания](../fractions-subtraction), [умножения](../fractions-multiplication) и [деления](../fractions-division) дробей вместе.

| Уровень | Какие числа | Уравнений всего |
|---|---|---|
| 1. до 3 | дроби со знаменателем 2 и 3 и целые до 3 | 186 |
| 2. до 5 | дроби со знаменателем до 5 и целые до 5 | 1002 |

Раунд — 20 случайных уравнений, по 5 каждого действия. На ответ — 10 секунд. Лучший результат уровня запоминается звёздами.

Урок работает на общем движке [math-drill](../math-drill) — там описано, как устроена игра. Здесь только настройки: `lesson.json` и `drill.json` (`mix` — какие уроки смешать, `"unknown": true` — уравнения, секунды, примеров в раунде, названия уровней).

## Собрать и посмотреть

```bash
(cd ../math-drill/game && npm install)              # один раз — TypeScript
node ../math-drill/game/build_scripts/build.mjs .   # → build/
open build/index.html                               # открывается и двойным кликом, без сервера
```
