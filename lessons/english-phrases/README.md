# 💬 Английский: фразы

Общая папка для уроков с английскими фразами: 300 самых ходовых фраз для детей («Hello!», «Can I have some water?», «It's my turn.»), их перевод, озвучка и общий движок игры. Это не урок — на главной её нет.

| Урок | Режим (`game.json`) | Что делаем |
|---|---|---|
| [🎧 Переведи на русский](../english-phrases-ru) | `to-russian` | слушаем фразу по-английски и говорим её по-русски |
| [💬 Скажи фразу по-английски](../english-phrases-en) | `to-english` | читаем фразу по-русски и говорим её по-английски |
| [🧩 Собери фразу](../english-phrases-assemble) | `assemble` | слушаем фразу и собираем её из карточек со словами |
| [⏳ Вчера, сейчас или завтра?](../english-tenses-listen) | `tenses-listen` | слушаем предложение и выбираем время |
| [🔁 Скажи вчера и завтра](../english-tenses-say) | `tenses-say` | говорим предложение в другом времени |

В уроках, где отвечают голосом, браузер распознаёт речь и проверяет ответ. Если ребёнок не знает ответа, везде есть кнопка 💡 «Подсказка». Уроки времён берут предложения не отсюда, а из общей папки [lessons/english-tenses](../english-tenses); движок у них этот же.

## Что где лежит

| Файл / папка | Что это |
|---|---|
| `data/topics.tsv` | 12 тем: ключ, иконка, название |
| `data/phrases.tsv` | фразы: тема, фраза, перевод, ещё переводы (через `\|`), ещё английские варианты (через `\|`) |
| `audio/` | **готовые звуки** английских фраз: `how-are-you.mp3`, `thank-you.mp3`… |
| `audio/ru/` | **готовые звуки** русских переводов, с теми же именами: `ru/how-are-you.mp3` |
| `game/` | движок игры: `index.html`, `style.css`, сборка `build_scripts/build.mjs`; код — `src/common.ts` (темы, очки, звук, распознавание и проверка речи) и по файлу на режим: `speak.ts` (`to-russian`, `to-english`), `assemble.ts`, `tenses.ts` (`tenses-listen`, `tenses-say`) |
| `tools/speak.py` | озвучка фраз (ElevenLabs или OpenAI) |
| `tools/review.html` | послушать все фразы и переводы, пометить неудачные звуки |
| `shared.json` | помечает папку общей: корневая сборка публикует только `audio/` |

Имя файла получается из английской фразы: строчные буквы, всё лишнее заменяется на дефис («How are you?» → `how-are-you`). Две фразы с одинаковым именем файла или одинаковым русским переводом сборка не пропустит: по русской фразе должно быть понятно, какую английскую говорить.

## Как уроки берут файлы

- Каждый урок — это `lesson.json` (`"uses": ["english-phrases"]` или `["english-tenses"]`) и `game.json` с одним полем `mode` (таблица выше). Своего кода у уроков нет, сборка запускает движок: `node ../english-phrases/game/build_scripts/build.mjs .` и кладёт игру в `build/` урока: `common.js`, файл режима и `data.js`. Части страницы, нужные не всем режимам, помечены классами `only-…` (см. `index.html`).
- Фразы попадают в `data.js` урока. Звуки **не копируются**: игра загружает их из `../english-phrases/audio/` на сайте или из `../../english-phrases/audio/` при локальной сборке. Service worker сохраняет папку вместе с уроком, так что без интернета звуки есть (а распознавание речи в Chrome без интернета не работает — тогда появляется кнопка «👍 Получилось»).
- Фраза без английского звука в игру не попадает. Перевод без звука читает голос системы (`speechSynthesis`), а если русского голоса нет — только показывается.

## Как проверяется ответ

Распознавание речи встроено в браузер (Web Speech API): `ru-RU` в «Переведи на русский», `en-US` в «Скажи фразу по-английски». Ответ сравнивается с переводом и со всеми вариантами из `phrases.tsv`. Проверка мягкая, но так, чтобы неправильный ответ не прошёл:

- **Порядок слов не важен**, знаки препинания и «ё»/«е» тоже. Цифры = слова: «мне 7 лет» = «мне семь лет», «3:00» = «three o'clock».
- **Русские окончания могут отличаться:** «я рада» за «я рад», «собаку» за «собака», «давай поиграем» за «давай играть». Но другое слово не пройдёт: «ветер» ≠ «вечер», «включи» ≠ «выключи», «пока» ≠ «покажи».
- **Английские сокращения раскрываются:** «I'm» = «I am», «don't» = «do not», «what's» = «what is», «OK» = «okay»; артикли не важны; «colour» = «color», «mum» = «mom».
- **Можно пропустить маленькое слово** во фразе из четырёх слов и длиннее: «я хочу игрушку» за «я хочу эту игрушку». Маленькие слова — `OPTIONAL` в `game/src/main.ts`: «пожалуйста», «это», «мне», «my», «is», «please»…
- **Лишними могут быть только маленькие слова:** «а как тебя зовут?» засчитается, а «How old are you» вместо «How are you» — нет.
- **«не» / «not» не прощается никогда:** «мне нравится» ≠ «мне не нравится».

Если правильный перевод не засчитывается — допишите его в колонку «ещё переводы» (или «ещё по-английски») в `data/phrases.tsv` и пересоберите урок.

## Добавить или поменять фразы

1. Поправьте `data/phrases.tsv` (новая тема — строка в `data/topics.tsv`).
2. `python3 tools/speak.py --dry-run`, потом `python3 tools/speak.py` и `python3 tools/speak.py --ru`: озвучится только то, чего ещё нет.
3. Послушайте в `tools/review.html` и пересоберите уроки: `npm run build` в корне репозитория.

## Озвучка

- **Английские фразы** — тот же голос, что у английских слов в [lessons/english](../english): ElevenLabs, Sarah (`EXAVITQu4vr4xnSDxMaL`), модель `eleven_multilingual_v2`, настройки с префиксом `EN_`.
- **Русские переводы** (`--ru`) — голос уроков чтения: ElevenLabs, Olga Orlova (`ELEVENLABS_VOICE`), модель `PHRASES_RU_MODEL` (по умолчанию `eleven_flash_v2_5`).

`tools/speak.py` использует код `../english/tools/speak.py` (запрос в сервис, выравнивание громкости через `lame`), поэтому обе папки нужны вместе. Ключ — `ELEVENLABS_API_KEY` в `.env` в корне репозитория (пример — [.env.example](../../.env.example)).

```bash
python3 tools/speak.py --dry-run                 # что будет озвучено и сколько символов — без запросов
python3 tools/speak.py --limit 5                 # первые 5 — послушать голос
python3 tools/speak.py                           # озвучить всё, чего нет
python3 tools/speak.py --only greetings,food     # только эти темы
python3 tools/speak.py --redo how-are-you,thank-you   # переозвучить отдельные фразы (по имени файла)

python3 tools/speak.py --ru --dry-run            # всё то же для русских переводов — с --ru
python3 tools/speak.py --ru --redo how-are-you   # переозвучить перевод (например, неверное ударение)
python3 tools/speak.py --ru --limit 5 --model eleven_multilingual_v2 --out compare/ru-v2   # сравнить модель
```

Синтезатор иногда ставит ударение неверно. Такой перевод можно переозвучить с `--redo` (ответ каждый раз немного другой) или поменять его текст в `phrases.tsv`. Папка `compare/` в git не попадает.

Проверка — с сервером из этой папки:

```bash
python3 -m http.server 8000      # → http://localhost:8000/tools/review.html
```

Если у перевода нет звука, подсказка в «Переведи на русский» читает его голосом системы (`speechSynthesis`), а «Скажи фразу по-английски» не показывает кнопку 🔊.
