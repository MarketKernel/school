# 🎲 Дроби вперемешку

Сложение, вычитание, умножение и деление дробей в одном раунде: `1/2 + 1/3`, `1 − 1/3`, `2/3 × 3/4`, `2 ÷ 2/3`.

Уровень N здесь — уровни N уроков [сложения](../fractions-addition), [вычитания](../fractions-subtraction), [умножения](../fractions-multiplication) и [деления](../fractions-division) дробей вместе.

| Уровень | Какие числа | Примеров всего |
|---|---|---|
| 1. до 3 | дроби со знаменателем 2 и 3 и целые до 3 | 93 |
| 2. до 5 | дроби со знаменателем до 5 и целые до 5 | 501 |

Раунд — 20 случайных примеров, по 5 каждого действия. На ответ — 10 секунд. Лучший результат уровня запоминается звёздами.

Урок работает на общем движке [math-drill](../math-drill) — там описано, как устроена игра. Здесь только настройки: `lesson.json` и `drill.json` (`mix` — какие уроки смешать, секунды, примеров в раунде, названия уровней).

## Собрать и посмотреть

```bash
(cd ../math-drill/game && npm install)              # один раз — TypeScript
node ../math-drill/game/build_scripts/build.mjs .   # → build/
open build/index.html                               # открывается и двойным кликом, без сервера
```
