# 🔦 Две щели

Самый знаменитый опыт квантовой физики. Волна проходит сквозь две щели и рисует на экране светлые и тёмные полоски, а электроны, пущенные по одному, сами собираются в такие же полоски — пока никто не подглядывает, через какую щель они летят.

- **🌊 Волна** — лампа слева (на телефоне сверху) посылает ровную волну на стенку с двумя щелями; за стенкой две круглые волны складываются в веер, а экран в конце показывает среднюю яркость — полоски.
- **⚛️ Электроны** — электроны вылетают из пушки по одному, сначала медленно, потом всё быстрее, и оставляют точки на экране. Счётчик «Электронов: N» в углу.
- **✌️ Две / ☝️ Одна** — открыть обе щели или закрыть одну (полоски пропадают).
- **🕵️ Шпион** (только для электронов) — датчик у щелей замечает, через какую щель пролетел электрон: полоски исчезают, остаются два пятна.
- **Нажатие на воду** — палец становится ещё одним источником волн (можно несколькими пальцами); в режиме электронов нажатие выпускает горсть электронов. 🔄 — начать заново (на узком телефоне кнопки нет: начинает заново повторное нажатие на выбранный режим), ⏸ (или пробел) — пауза.

Что увидеть:

- Тёмные лучи веера за стенкой — там волны от двух щелей всё время гасят друг друга; они упираются в тёмные полоски экрана.
- Первые электроны ложатся как попало, полоски проявляются только через несколько тысяч точек.
- Со «Шпионом» те же электроны дают два пятна без полосок.

Волна — честное волновое уравнение `u_tt + 2σu_t = c²∇²u` на сетке видеокарты (до 512 клеток по длинной стороне, явная схема «чехарда», две текстуры по очереди): в стенке `u = 0`, у краёв, за лампой и за экраном — поглощающий слой с растущим σ, экран показывает скользящее среднее `u²`. Электроны выбирают точку попадания по `|ψ|²`: для двух щелей — огибающая `sinc²` (ширина щели) на полоски `cos²` (расстояние между щелями), для одной щели и со шпионом — горбы за щелями без полосок. Код — [double-slit.ts](../physics/game/src/double-slit.ts).
