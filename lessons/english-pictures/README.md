# 👂 Найди картинку

Диктор называет английское слово, ребёнок находит его среди четырёх картинок. Слова, картинки и звуки — те же 300, что в «Скажи по-английски». Они лежат в общей папке [lessons/english](../english), этот урок ничего из неё не копирует.

- Слово звучит само в начале каждого раунда. Кнопка 🔊 «Послушай» повторяет его.
- **Нашёл с первого раза** — ⭐ +1, картинка подписывается словом и переводом, через секунду следующее слово.
- **Ошибся** — картинка тускнеет и подписывается своим словом, диктор называет её («elephant»), а потом повторяет нужное слово. Очка за такой раунд нет, но искать дальше можно.
- Написанное слово показывается только после ответа: ребёнок должен слушать, а не читать.
- Темы те же, что в «Скажи по-английски», плюс «🎲 Вперемешку». Под темой видно, сколько слов уже угадано с первого раза. Неверные варианты берутся из той же темы.
- Почти одинаковые картинки (`mom` и `woman`, `cheese` и `butter`, `boat` и `ship`) никогда не попадаются вместе. Их список — `../english/data/similar.tsv`.
- Клавиши: `1`–`4` — выбрать картинку, пробел — послушать ещё раз.
- Очки и прогресс хранятся в браузере отдельно от «Скажи по-английски».
- В начале кнопка «Начать ▶»: без нажатия браузер (особенно на iPhone) не даст включить звук.

## Запустить игру

```bash
cd game
npm install
npm start          # собрать и открыть build/index.html
npm run serve      # или собрать и открыть на http://localhost:8000/english-pictures/game/build/
```

`npm run serve` запускает сервер из папки `lessons/`, чтобы были доступны файлы из `lessons/english`. Сборка ([game/build_scripts/build.mjs](game/build_scripts/build.mjs)) берёт только слова, у которых есть и звук, и картинка.
