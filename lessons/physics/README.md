# ✨ Чудеса физики — общий движок

Движок уроков-симуляций: каждое явление — отдельный урок `lessons/physics-<сцена>/` на весь экран. Это не урок (нет `lesson.json`), а код, из которого собираются уроки раздела «Чудеса физики».

Явления нарочно сложные: хаос, квантовая механика, чёрные дыры, четвёртое измерение. Ребёнок не обязан понимать их до конца — сцена должна завораживать и вызывать вопросы. Поэтому каждая сцена:

- сразу, без нажатий, показывает самое красивое;
- отвечает на касания: запустить, бросить, потянуть, нарисовать (на телефоне — несколькими пальцами);
- держит сверху строчку-загадку, а за кнопкой **?** — карточку «Что тут происходит?» с простым объяснением;
- имеет кнопку ⏸ (и пробел). Если в системе включено «уменьшение движения», сцена стартует на паузе.

## Как устроено

```
physics/game/
  index.html             — страница: холст на весь экран, заголовок, панель кнопок, карточка «Что тут происходит?»
  style.css              — тёмная «ночная» сцена, пастельные кнопки, шрифт Nunito
  src/common.ts          — общее: холст, цикл анимации, касания, кнопки и ползунки, вращение 3D, помощники WebGL 2
  src/<сцена>.ts         — сама симуляция, по файлу на явление (каждый — свой namespace)
  build_scripts/build.mjs — сборка одного урока
```

Урок — это папка с тремя файлами:

| Файл | Что это |
|---|---|
| `lesson.json` | название, описание и иконка для главной, раздел «Чудеса физики», `order` (501…), команда сборки |
| `scene.json` | `scene` — какой файл из `src/` взять (`"billiard"`), `question` — строчка-загадка сверху, `about` — абзацы карточки «Что тут происходит?» |
| `README.md` | что показывает сцена, кнопки, на что посмотреть, как это посчитано |

Сборка урока компилирует только `common.ts` и файл его сцены и кладёт в `<урок>/build/`: `index.html`, `style.css`, `data.js` (тексты из `scene.json`), `common.js`, `<сцена>.js`. Страница открывается и двойным кликом — без сервера и без `fetch`. Всё рисуется кодом: картинок, звуков и библиотек нет (звук, где он есть, синтезирует WebAudio).

## Собрать и посмотреть

```bash
cd lessons/physics-billiard
(cd ../physics/game && npm install)                 # один раз — TypeScript
node ../physics/game/build_scripts/build.mjs .      # → build/
open build/index.html
(cd ../physics/game && npm run check)               # проверить типы всех сцен разом
```

## Новая сцена

1. `src/<сцена>.ts` — код в `namespace <Сцена> { … }`, по образцу [billiard.ts](game/src/billiard.ts): холст `canvas2d()` или `canvasGL()`, цикл `startLoop((dt) => …)`, касания `onPointer({ down, move, up })`, кнопки `addButton` / `addChoice` / `addSlider`, подсказка `showHint("…")`. Фигуру, которую нужно видеть целиком, вписывайте в `freeArea()` — между заголовком и кнопками.
2. Папка `lessons/physics-<сцена>/` с `lesson.json`, `scene.json` и `README.md` — скопируйте из [physics-billiard](../physics-billiard) и поменяйте.
3. Строчка в таблице уроков корневого `README.md`.

Корневая сборка (`npm run build`) находит урок сама.
