# 🌀 Скрытые измерения

Радужная фигура Калаби — Яу — знаменитая картинка из теории струн: так рисуют крошечные свёрнутые измерения, которые, может быть, спрятаны в каждой точке пространства. Это не симуляция, а математика: четырёхмерная поверхность, заданная одним уравнением, и её трёхмерная «тень». Угол, под которым мы смотрим на неё в скрытом направлении, медленно меняется, и фигура переливается.

- **Потянуть пальцем или мышью** — покрутить фигуру; отпущенная, она медленно вращается сама. **Колесо мыши или два пальца** — приблизить.
- **Степень n** (2…6) — из скольких кусочков-лепестков сложена фигура: их `n × n`.
- **🕸️ Сетка** — показать или спрятать линии сетки; ⏸ (или пробел) — пауза.

Что увидеть:

- Каждый цветной лепесток — отдельный кусочек, но все они срастаются краями в одну поверхность.
- При `n = 2` фигура простая, похожая на перекрученное кольцо, при `n = 5` — та самая «инопланетная» фигура из книг про теорию струн.

Метод: срез многообразия Калаби — Яу по картинке А. Хансона (1994) — комплексная кривая `z₁ⁿ + z₂ⁿ = 1` в `C²`. Каждая пара `k₁, k₂ ∈ {0 … n−1}` даёт кусочек `z₁ = e^(2πik₁/n)·cosh(z)^(2/n)`, `z₂ = e^(2πik₂/n)·(−i·sinh z)^(2/n)` при `z = x + iy`, `x ∈ [−1, 1]`, `y ∈ [0, π/2]`. Точка рисуется в `(Re z₁, Re z₂, cos α·Im z₁ + sin α·Im z₂)`, угол `α` медленно качается. Сетка пересчитывается на процессоре каждый кадр (нормали — по соседним точкам), рисуется WebGL 2 с буфером глубины: цвет по кусочку, мягкий свет, блик и светящийся край. Код — [calabi-yau.ts](../physics/game/src/calabi-yau.ts).

Урок работает на общем движке [physics](../physics). Здесь только настройки:

| Файл | Что это |
|---|---|
| `lesson.json` | название, иконка, раздел на главной и команда сборки |
| `scene.json` | какая сцена (`calabi-yau`), строчка-загадка и текст карточки «Что тут происходит?» |
