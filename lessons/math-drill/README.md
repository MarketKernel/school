# 🔢 Тренажёр примеров — общий движок

Это не урок, а общий код для уроков-тренажёров на счёт: [math-addition](../math-addition), [math-subtraction](../math-subtraction), [math-multiplication](../math-multiplication), [math-division](../math-division), [math-mix](../math-mix), [math-equations](../math-equations) и шести уроков с дробями (`fractions-*`). У папки нет `lesson.json`, поэтому на главной её нет.

## Как играть

- Сверху — уровни, от простых к сложным. Под номером уровня — звёзды за лучший результат: ⭐ от 50% верных, ⭐⭐ от 70%, ⭐⭐⭐ от 90%. Открывается первый уровень, где ещё нет трёх звёзд; переключаться можно в любой момент.
- Раунд — все примеры уровня по одному разу, в случайном порядке. Если в `drill.json` задан `count` — столько случайных примеров уровня, без повторов.
- В тетрадных клеточках — пример: `3 + 4 = [ ]`. Внизу четыре ответа: один верный, три неверных.
- На ответ — 5 секунд (`seconds` в `drill.json`; полоска под примером тает и краснеет к концу): посчитать на пальцах или калькуляторе не успеть, ответ надо знать.
- Не успел или ошибся — показываем правильный ответ («Запомни: 3 + 4 = 7») и сразу следующий пример.
- Сверху счёт: какой пример, сколько верно ✅, сколько ошибок и пропусков ❌ и среднее время верного ответа ⏱. В конце — итог со звёздами и «Ещё раз»; от двух звёзд — ещё и «Дальше» на следующий уровень.
- Если свернуть вкладку или заблокировать телефон, таймер встаёт на паузу.

Неверные ответы не случайные числа, а похожие на правду: соседние числа (±1, ±2, ±3) и типичные промахи — соседний ответ из таблицы умножения (7 × 8 → 63), сложение вместо вычитания (12 − 5 → 17), делитель вместо частного. Ответы стоят по возрастанию.

Лучшие результаты хранятся в браузере (`localStorage`) — у каждого устройства свои. Если хранилище недоступно, тренажёр работает, просто не запоминает звёзды.

## Настройки урока — `drill.json`

Урок на этом движке — папка с тремя файлами: `lesson.json`, `drill.json`, `README.md`.

```json
{
  "op": "add",
  "from": 0,
  "to": 9,
  "seconds": 5,
  "levels": [
    {"name": "до 5", "hint": "Сумма до 5", "upTo": 5},
    {"name": "до 10", "hint": "Сумма от 6 до 10", "upTo": 10}
  ]
}
```

| Поле | Что это |
|---|---|
| `op` | действие: `add` — сложение, `sub` — вычитание, `mul` — умножение, `div` — деление |
| `from`, `to` | числа, из которых строятся примеры: `x + y` и `x × y`, где `x` и `y` от `from` до `to` |
| `seconds` | секунд на один пример |
| `count` | необязательно: примеров в раунде. Без него раунд — все примеры уровня |
| `unknown` | необязательно: `true` — уравнения, см. ниже |
| `fractions` | необязательно: `true` — примеры с дробями, см. ниже |
| `levels` | уровни от простых к сложным |
| `levels[].name` | короткая подпись на кнопке уровня: «до 5», «на 2 и 5» |
| `levels[].hint` | что за уровень — пишется перед началом раунда |
| `levels[].upTo` | для `add` и `sub`: уровень берёт примеры, где `x + y` не больше `upTo` |
| `levels[].tables` | для `mul` и `div`: уровень берёт примеры, где `x` или `y` — одно из этих чисел |
| `levels[].denominators` | только с `fractions`, необязательно: `"same"` или `"different"`, см. ниже |
| `levels[].take` | только с `mix`, необязательно: какой уровень взять у какого урока, см. ниже |

Каждый пример попадает в **первый** подходящий уровень. Поэтому у сложения достаточно верхней границы (`5`, `10`, `13`, `18`), а у умножения `[3, 4]` после `[2, 5]` значит «на 3 и 4, кроме уже пройденных на 2 и 5». Сборка печатает, сколько примеров в каждом уровне, и останавливается, если какой-то уровень пустой.

Вычитание и деление — это сложение и умножение наоборот: `(x + y) − y = x` и `(x × y) ÷ y = x`. Поэтому ответ никогда не бывает отрицательным или дробным, а при `from: 0, to: 9` ответ — от 0 до 9. На ноль не делим. Уровни у них считаются по тем же `x` и `y`: у вычитания `upTo` ограничивает уменьшаемое, у деления `tables` — делитель или частное.

### Дроби — `fractions`

С `"fractions": true` вместо `from` и `to` числа берутся такие: правильные дроби со знаменателем до `upTo` (1/2, 2/3, 3/5…) и целые числа до `upTo`. У уровней всех четырёх действий тогда `upTo`:

```json
{
  "op": "add",
  "fractions": true,
  "seconds": 10,
  "count": 20,
  "levels": [
    {"name": "до 3", "hint": "Сложение: знаменатели 2 и 3, целые до 3", "upTo": 3},
    {"name": "до 5", "hint": "Сложение: знаменатели до 5, целые до 5", "upTo": 5}
  ]
}
```

- В каждом примере хотя бы одна дробь — целые с целыми есть в уроках на числа.
- Пример попадает в первый уровень, где все его числа (числители, знаменатели, целые) не больше `upTo`.
- `levels[].denominators` (необязательно) сужает уровень: `"same"` — только две дроби с одинаковым знаменателем (`1/5 + 2/5`), `"different"` — всё остальное (`1/2 + 1/3`, `2 + 1/3`: у целого знаменатель 1). Так у [сложения](../fractions-addition) и [вычитания](../fractions-subtraction) дробей сначала два уровня с общим знаменателем, потом два с разными:

```json
{"name": "общий до 7", "hint": "Сложение: одинаковые знаменатели до 7", "upTo": 7, "denominators": "same"},
{"name": "разные до 3", "hint": "Сложение: разные знаменатели 2 и 3, целые до 3", "upTo": 3, "denominators": "different"}
```
- Вычитание — только когда уменьшаемое больше вычитаемого: ответ положительный, без нуля. Деление — любое, на ноль делить нечего.
- Ответ всегда несократимый (2/4 → 1/2), больше единицы — неправильной дробью (4/3), целый — целым числом (1/2 + 1/2 = 1).
- Пример записан по-школьному: числитель в клетке над чертой, знаменатель под ней, черта лежит на линии тетради; знаки стоят на той же линии.
- Неверные ответы — типичные ошибки: числители и знаменатели сложены отдельно (1/2 + 1/3 → 2/5), умножение вместо деления, перевёрнута не та дробь, плюс соседние дроби.

`mix` и `unknown` работают и с дробями — так устроены [fractions-mix](../fractions-mix) и [fractions-equations](../fractions-equations).

### Вперемешку — `mix`

Вместо `op`, `from`, `to` можно перечислить другие уроки-тренажёры — их примеры смешаются ([math-mix](../math-mix)):

```json
{
  "mix": ["math-addition", "math-subtraction", "math-multiplication", "math-division"],
  "seconds": 5,
  "count": 20,
  "levels": [
    {"name": "лёгкий", "hint": "Сложение и вычитание до 5, умножение и деление на 0 и 1"}
  ]
}
```

Уровень N такого урока — уровни N всех перечисленных уроков вместе, поэтому у его уровней только `name` и `hint`. Если у уроков разное число уровней, уровень может взять у некоторых другой номер — `take` (счёт с 1, остальные уроки дают уровень N):

```json
{"name": "до 3", "hint": "…", "take": {"fractions-addition": 3, "fractions-subtraction": 3}}
```

Так [fractions-mix](../fractions-mix) берёт у сложения и вычитания дробей уровни с разными знаменателями, а у умножения и деления — уровни 1 и 2. С `count` раунд берёт поровну примеров каждого урока: при `count: 20` и четырёх уроках — по 5. Знак у каждого примера свой, цвет страницы — бирюзовый.

### Уравнения — `unknown`

С `"unknown": true` (вместе с `op` или с `mix`) каждый пример превращается в два уравнения: x стоит вместо первого или второго числа — `3 + 4 = 7` → `x + 4 = 7` и `3 + x = 7`. Ответ — то число, которое спрятано. Уравнения, где x может быть любым (`x × 0 = 0`, `0 × x = 0`, `0 ÷ x = 0`), пропускаются. Неверные ответы — переписанное из уравнения число или обратное действие наоборот (для `x + 4 = 7` — 11). Цвет страницы — синий ([math-equations](../math-equations)).

Название и иконка страницы берутся из `lesson.json` урока. Цвет — по действию: розовый, голубой, оранжевый, фиолетовый, у смешанного — бирюзовый, у уравнений — синий (`body[data-op]` в `game/style.css`).

`lesson.json` урока собирает его так:

```json
"build": "(cd ../math-drill/game && npm ci) && node ../math-drill/game/build_scripts/build.mjs .",
"publish": "build"
```

## Собрать и посмотреть один урок

Из папки урока, например `lessons/math-addition`:

```bash
(cd ../math-drill/game && npm install)              # один раз — TypeScript
node ../math-drill/game/build_scripts/build.mjs .   # → build/
open build/index.html                               # открывается и двойным кликом, без сервера
```

## Что где лежит

| Файл | Что это |
|---|---|
| `game/src/main.ts` | логика: уровни, неверные ответы, таймер, счёт, звёзды |
| `game/index.html`, `game/style.css` | страница и оформление; в `index.html` сборка подставляет название и иконку урока |
| `game/build_scripts/build.mjs` | сборка урока в его папку `build/`: строит примеры, раскладывает их по уровням и кладёт в `build/data.js` |
