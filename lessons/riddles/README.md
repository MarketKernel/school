# 🦉 Загадки

Урок для детей 7–8 лет: голос читает загадку, ребёнок собирает отгадку из слогов — как в [🪄 Волшебных словах](../read-potter), только вместо слова звучит загадка.

## Как играть

- Загадка звучит сама, когда появляется; большая зелёная кнопка 🔊 читает её ещё раз. Самую первую загадку браузер сам не играет — нужно нажать 🔊.
- Под кнопкой — пустые клеточки отгадки, разбитые на слоги, внизу — карточки: слоги и буквы отгадки и столько же похожих неверных. Каждую карточку можно послушать.
- «Проверить» читает собранное по слогам, клеточки становятся зелёными или красными. Ошибку можно стереть (⌫ или Backspace).
- Отгадка из нескольких слов («Три медведя») — несколько рядов клеточек, по ряду на слово.
- Три уровня по длине отгадки: «Опушка» 🌼 — 2–3 карточки («Мел», «Берёза»), «Лесная тропа» 🍄 — 4 («Компас»), «Совиное дупло» 🦉 — 5 и больше («Одуванчик», «Гадкий утёнок»). Уровень пройден, когда отгаданы все его загадки; «Другая загадка» откладывает загадку на потом.

Игра собирается общим движком [read-game](../read-game) в режиме `riddle`: `lesson.json` + `game.json` (уровни, окна, конфетти) + `theme.css` (лесные цвета). Звуки слогов — из [lessons/russian](../russian), звуки загадок сборка копирует из `audio/`.

```sh
npm run build                                                   # весь сайт
node lessons/read-game/game/build_scripts/build.mjs lessons/riddles && open lessons/riddles/build/index.html
```

## Материалы

| Файл | Что это |
|---|---|
| `data/source.txt` | исходный текст: строки загадки, под ними ответ в скобках «(Молния)»; строка «Загадки …» между загадками — название раздела |
| `data/riddles.json` | загадки, подготовленные к озвучке (делает `tools/prepare.py`); игра берёт из него `id` и `answer` |
| `data/words_split.txt` | слова отгадок по слогам — делает `russian/tools/syllables.py`, по нему озвучиваются недостающие слоги |
| `audio/<id>.mp3` | озвученные загадки (делает `tools/voice.py`); отгадки не озвучиваются — ребёнок собирает их сам |

Поля загадки в `riddles.json`:

| Поле | Что это |
|---|---|
| `id` | имя звука: отгадка латиницей («Дни недели» → `dni-nedeli`) |
| `section` | раздел из исходника |
| `lines` | текст по строкам стиха, как его покажем на экране: с «ё», «—» и исправленными опечатками |
| `answer` | ответ |
| `tts` | текст для Yandex SpeechKit с [разметкой](https://aistudio.yandex.ru/docs/ru/speechkit/tts/markup/tts-markup): `+` перед ударной гласной там, где синтезатор может ошибиться («сто+ит», «отл+ого»), `<[small]>` — пауза в конце строки без знака препинания |
| `fixes` | что модель поменяла по сравнению с исходником — стоит просмотреть |
| `source` | загадка как в `source.txt`: по нему скрипт замечает, что исходник изменился |

## Подготовка — `tools/prepare.py`

Скрипт сам делит `source.txt` на загадки, а каждую загадку отправляет в OpenAI (`OPENAI_API_KEY` из `.env` в корне репозитория; модель — `OPENAI_TEXT_MODEL`, по умолчанию `gpt-5.5`). Модель разбивает слитые строки стиха, ставит «ё», исправляет опечатки и расставляет разметку для синтезатора.

```sh
python3 lessons/riddles/tools/prepare.py --dry-run          # как разбился текст, без запросов
python3 lessons/riddles/tools/prepare.py --limit 3          # первые 3 — проверить результат
python3 lessons/riddles/tools/prepare.py                    # всё новое и изменённое
python3 lessons/riddles/tools/prepare.py --redo molniya     # заново эти загадки (id через запятую)
python3 lessons/riddles/tools/prepare.py --force            # заново все
```

Загадки, которые уже есть в `riddles.json`, скрипт не трогает, пока их текст в `source.txt` не изменится. Поэтому ошибки модели — чаще всего неверное ударение — можно спокойно исправлять в `riddles.json` вручную. Если слова в ответе модели не совпали с исходником, скрипт пишет «проверьте».

Новые загадки дописываются в `source.txt` в том же формате и готовятся повторным запуском.

## Озвучка — `tools/voice.py`

Читает поле `tts` каждой загадки из `riddles.json` и озвучивает его через Yandex SpeechKit (API v1). Ключ — `YANDEX_API_KEY` в `.env`: API-ключ сервисного аккаунта с ролью `ai.speechkit-tts.user`. Звуки: `audio/<id>.mp3`, ответы не озвучиваются. Громкость выравнивается так же, как у слогов (нужен `lame`: `brew install lame`).

Настройки в `.env`: `YANDEX_VOICE` (по умолчанию `filipp` — выбран на слух; в API v1 есть ещё `ermil`, `zahar`, `alena`, `jane`, `marina`, `omazh`), `YANDEX_EMOTION` (`good`), `YANDEX_SPEED` (`0.9` — чуть медленнее обычного).

```sh
python3 lessons/riddles/tools/voice.py --dry-run                # что будет озвучено и сколько символов
python3 lessons/riddles/tools/voice.py --redo beryoza           # одна загадка
python3 lessons/riddles/tools/voice.py                          # всё, чего ещё нет
python3 lessons/riddles/tools/voice.py --redo beryoza --compare filipp,ermil,alena,jane
    # одна загадка разными голосами в compare/<голос>/ — послушать и выбрать; audio/ не трогает
```

Если синтезатор ошибся в ударении, поправьте `+` в `tts` в `riddles.json` и переозвучьте загадку через `--redo <id>`.
