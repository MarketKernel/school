# 🗣️ Скажи по-английски

Первые 300 английских слов для детей. Ребёнок видит картинку и слово, нажимает 🔊 и слушает, как оно звучит. Сразу после этого включается микрофон: нужно повторить слово вслух. Если браузер узнал слово — ⭐ +1.

Слова разбиты на 13 тем («Животные», «Еда», «Цвета и формы», «Числа», «Что делаем?», «Какой?»…), есть ещё «🎲 Вперемешку». Под темой видно, сколько её слов уже получилось. Когда получились все — тема пройдена. Сначала чаще попадаются слова, которые ещё не получались. Очки и прогресс хранятся в браузере.

Слова, картинки и звуки лежат в общей папке [lessons/english](../english): там же написано, как их добавлять и перегенерировать. Этот урок ничего из неё не копирует.

## Как проверяется произношение

Через распознавание речи, встроенное в браузер (Web Speech API, язык `en-US`). Библиотеки и ключи не нужны.

- **Где работает:** Chrome и Edge (компьютер, Android), Safari (macOS, iOS). В Firefox распознавания нет.
- **Нужен интернет:** Chrome отправляет звук на серверы Google. Без сети и в Firefox появляется кнопка «👍 Получилось»: взрослый слушает и нажимает её сам.
- **Проверка мягкая, чтобы не расстраивать ребёнка.** Засчитывается, если слово есть среди пяти вариантов распознавания. Подходят и «a cat», и «cats», и одна ошибочная буква в длинном слове, и созвучные слова из колонки «тоже засчитать» в `../english/data/words.tsv`: «two» → «to», «too». Цифры тоже подходят: «2» = «two».
- Если не получилось, игра показывает, что услышал браузер: «Похоже на «cut». Попробуй ещё раз!».
- Микрофон включается только после того, как слово договорено, иначе браузер услышит динамик.

## Запустить игру

```bash
cd game
npm install
npm start          # собрать и открыть build/index.html
npm run serve      # или собрать и открыть на http://localhost:8000/english-words/game/build/
```

`npm run serve` запускает сервер из папки `lessons/`, чтобы были доступны файлы из `lessons/english`. Микрофон браузер даёт только по `https://` или на `localhost`, поэтому распознавание проверяйте через `npm run serve`: при открытии двойным кликом оно может не заработать. На GitHub Pages всё работает.

Сборка ([game/build_scripts/build.mjs](game/build_scripts/build.mjs)) кладёт в `game/build/` страницу, код и `data.js` со словами. Слово без звука в игру не попадает. Слово без картинки попадает, вместо картинки показывается иконка темы.
