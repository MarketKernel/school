# 📖 «Собери слово» — общий движок уроков чтения

Это не урок, а общий код для уроков, где ребёнок читает по слогам: [🐷 Собери слово](../read-syllables), [🪄 Волшебные слова](../read-potter) и [🎤 Прочитай вслух](../read-potter-aloud). У папки нет `lesson.json`, поэтому на главной её нет.

Звуки букв и слогов лежат в общей папке [lessons/russian](../russian). Слова и картинки — в уроке или в общей папке слов, если они нужны нескольким урокам (например, [lessons/potter](../potter)).

## Два режима

У движка два режима — `mode` в `game.json` урока.

**`assemble` — собери слово** (по умолчанию; «Собери слово», «Волшебные слова»):

- Ребёнок видит картинку и пустые клеточки слова, слушает слово по слогам (большая кнопка с динамиком) и собирает его из карточек внизу.
- Карточки — слоги («ма», «ви») и отдельные буквы. Слог — это пара «согласная + гласная», `ь` и `ъ` пристают к предыдущей карточке. На каждую верную карточку есть одна похожая неверная: слог вместо слога, буква вместо буквы. Каждую карточку можно послушать.
- «Проверить» проигрывает собранное по слогам, клеточки становятся зелёными или красными. Ошибку можно стереть (⌫ или Backspace) и попробовать ещё раз.

**`aloud` — прочитай вслух** («Прочитай вслух»):

- Ребёнок видит картинку и слово, разбитое на плашки-слоги («к · ры · са»), нажимает 🎤 и читает вслух. Распознавание речи браузера (Web Speech API, `ru-RU`) проверяет, под словом видно, что оно услышало.
- Совпало — +1 ⭐ (счёт хранится в `localStorage`) и огонёк уровня. Не совпало — «Попробуй ещё раз».
- 🔊 — подсказка: слово звучит по слогам, но звёздочки после неё нет.
- Без распознавания (Firefox, нет интернета, нет микрофона) появляется кнопка «👍 Получилось» для взрослого.
- Проверка мягкая: пробелы не важны («га ри» = «Гарри»), «ё» = «е», в словах от 5 букв прощается одна ошибочная буква. Подробно — в [README урока](../read-potter-aloud/README.md#распознавание-речи).

**Общее для обоих режимов:**

- Три уровня — по числу частей слова, а не слогов: «до-мик» проще, чем «с-т-ра-ш-но», хотя слогов в них поровну.

  | Уровень | Слова |
  |---|---|
  | 1 | из 2–3 частей: «до-мик» |
  | 2 | из 4 частей |
  | 3 | из 5 частей и больше |

- Под каждым уровнем 5 огоньков, каждый разгорается за 5 слов. Когда собрано (прочитано) 25 слов, появляется окно «уровень пройден», после третьего уровня — финал и «Играть снова».
- В игру попадают только русские слова, где хотя бы две гласные. Если у слов уровня есть картинки, показываются только слова с картинками. Слова не повторяются, пока не пройдены все.
- Имена пишутся с заглавной буквы («Гарри»): карточки строчные, а в клеточке первая буква становится заглавной.

## Урок на этом движке

```
lessons/<урок>/
  lesson.json        — название, иконка, раздел, "uses": ["russian"] и команда сборки
  game.json          — режим, откуда слова, названия уровней, окна, конфетти, стиль картинок
  theme.css          — необязательно: свои цвета поверх style.css движка
  data/words.txt     — слова: «частота<TAB>слово» (tools/words.py) или по слову в строке
  data/pictures.tsv  — к каким словам рисовать картинку и что на ней (уровень, слово, описание)
  images/, images.json — готовые картинки (tools/draw.py)
  README.md
```

Если `data/words.txt` нет, слова берутся из `data/pictures.tsv` — так удобнее, когда у каждого слова есть картинка.

Если слова и картинки нужны нескольким урокам, `data/`, `images/` и `images.json` лежат не в уроке, а в общей папке (`lessons/potter/` с `shared.json`). Урок называет её в `game.json` (`"words": "potter"`) и в `lesson.json` (`"uses": ["russian", "potter"]`). Картинки тогда не копируются в урок: игра загружает их из общей папки, как и звуки. `pictureStyle` такой папки — в её `shared.json`.

`lesson.json`:

```json
{
  "title": "Прочитай вслух",
  "description": "Читаем вслух: …",
  "subject": "Чтение",
  "icon": "🎤",
  "uses": ["russian", "potter"],
  "build": "(cd ../read-game/game && npm ci) && node ../read-game/game/build_scripts/build.mjs .",
  "publish": "build"
}
```

`game.json`:

| Поле | Что это |
|---|---|
| `mode` | `"assemble"` — собрать слово из карточек (по умолчанию), `"aloud"` — прочитать вслух |
| `words` | необязательно: общая папка со словами и картинками, `"potter"`. Без него — `data/` и `images/` самого урока |
| `levels` | ровно три уровня: 2–3, 4 и 5+ частей |
| `levels[].name`, `icon` | подпись и значок на кнопке уровня |
| `levels[].done` | окно, когда уровень пройден: `title`, `text`, `button` и необязательный `icon` (иначе — значок уровня). `{n}` в `text` заменяется на число слов. Окно третьего уровня — финал игры, его кнопка начинает всё сначала |
| `doneIcon` | значок на кнопке пройденного уровня: 🏠 |
| `confetti` | значки, которые сыплются при верном ответе |
| `pictureStyle` | общий стиль картинок для `tools/draw.py` — чтобы все они были как из одной книжки (у общей папки слов — в `shared.json`) |

`theme.css` переопределяет переменные из [game/style.css](game/style.css): `--sky`, `--main`, `--main-dark`, `--main-soft`, `--tile-border`, `--tile-shadow`, `--level-1` … `--level-3` (и `-soft`), `--grass`.

### Новый урок чтения

1. Скопируйте `lesson.json`, `game.json` и `theme.css` из [read-potter](../read-potter) (или [read-potter-aloud](../read-potter-aloud) для чтения вслух) и поменяйте.
2. Слова и картинки: свои — `data/pictures.tsv` в уроке (и `data/words.txt`, если слов больше, чем картинок); уже готовые — `"words"` с общей папкой.
3. Нарисуйте картинки и озвучьте новые слоги — см. ниже.
4. Строка в таблице уроков в корневом `README.md`.

## Картинки

```bash
python3 tools/draw.py potter --limit 3                 # первые 3 — проверить стиль
python3 tools/draw.py potter                           # нарисовать всё, чего ещё нет
python3 tools/draw.py read-syllables --redo домик,лето # перерисовать отдельные
```

Папка — урок или общая папка слов: имя в `lessons/` или путь. Что рисовать, задаёт её `data/pictures.tsv`; общий стиль — `pictureStyle` в `game.json` урока или `shared.json` общей папки. Модель по умолчанию — `gpt-image-1-mini`, качество `low`: картинки уменьшаются до 256 px, большего не нужно. Нужны ключ `OPENAI_API_KEY` в `.env` в корне репозитория и macOS (`sips` уменьшает картинки).

Проверить на глаз — страница `tools/pictures.html`. Ей нужен сервер, запущенный из папки `lessons/`:

```bash
cd lessons && python3 -m http.server 8000
# http://localhost:8000/read-game/tools/pictures.html?lesson=potter
```

Клик помечает неудачные картинки, внизу появляется команда `draw.py … --redo …`.

## Слова из текста

Урок «Собери слово» берёт слова из сказки. Для другого текста:

```bash
python3 tools/words.py ../read-syllables/data/text1.txt -o ../read-syllables/data/words.txt
```

## Звуки

Новые слова часто приносят новые слоги. Звуки общие — они озвучиваются в [lessons/russian](../russian):

```bash
python3 ../russian/tools/syllables.py          # слоги всех уроков чтения
python3 ../russian/tools/speak.py --dry-run    # каких не хватает
python3 ../russian/tools/speak.py              # озвучить только недостающие
```

Слог без звука не ломает игру: он звучит по буквам.

## Собрать и посмотреть

```bash
(cd game && npm install)                          # один раз — TypeScript
node game/build_scripts/build.mjs ../read-potter  # → lessons/read-potter/build/
open ../read-potter/build/index.html              # открывается и двойным кликом, без сервера
```

Сборка ([game/build_scripts/build.mjs](game/build_scripts/build.mjs)) кладёт в `build/` урока страницу, стили, `theme.css`, код (`common.js` и файл своего режима) и `data.js` со словами, историей урока и списками звуков; картинки — только если они свои, а не из общей папки. Звуки она не копирует: игра берёт их из `lessons/russian/audio/`.

Код игры:

| Файл | Что в нём |
|---|---|
| [game/src/common.ts](game/src/common.ts) | общее: разбивка на слоги, звуки, уровни, выбор слова, клеточки, окна, конфетти |
| [game/src/assemble.ts](game/src/assemble.ts) | режим «собери слово»: карточки, проверка |
| [game/src/aloud.ts](game/src/aloud.ts) | режим «прочитай вслух»: распознавание речи, сравнение, счёт |

Это обычные скрипты, не модули (так игра открывается и двойным кликом): страница подключает `data.js`, `common.js` и файл режима. Каждый режим завёрнут в свой `namespace`, чтобы их имена не пересекались.

Разбивка на слоги написана дважды — `splitWord` в [game/src/common.ts](game/src/common.ts) и `split_word` в [../russian/tools/syllables.py](../russian/tools/syllables.py). Меняйте их вместе.
