# 📖 «Собери слово» — общий движок уроков чтения

Это не урок, а общий код для уроков, где ребёнок читает по слогам: [🐷 Собери слово](../read-syllables) и [🪄 Волшебные слова](../read-potter). У папки нет `lesson.json`, поэтому на главной её нет.

Звуки букв и слогов лежат в общей папке [lessons/russian](../russian), картинки и слова — в каждом уроке свои.

## Как играть

- Ребёнок видит картинку и пустые клеточки слова, слушает слово по слогам (большая кнопка с динамиком) и собирает его из карточек внизу.
- Карточки — слоги («ма», «ви») и отдельные буквы. Слог — это пара «согласная + гласная», `ь` и `ъ` пристают к предыдущей карточке. На каждую верную карточку есть одна похожая неверная: слог вместо слога, буква вместо буквы. Каждую карточку можно послушать.
- «Проверить» проигрывает собранное по слогам, клеточки становятся зелёными или красными. Ошибку можно стереть (⌫ или Backspace) и попробовать ещё раз.
- Три уровня — по числу карточек, а не слогов: «до-мик» проще, чем «с-т-ра-ш-но», хотя слогов в них поровну.

  | Уровень | Слова |
  |---|---|
  | 1 | из 2–3 карточек: «до-мик» |
  | 2 | из 4 карточек |
  | 3 | из 5 карточек и больше |

- Под каждым уровнем 5 огоньков, каждый разгорается за 5 слов. Когда собрано 25 слов, появляется окно «уровень пройден», после третьего уровня — финал и «Играть снова».
- В игру попадают только русские слова, где хотя бы две гласные. Если у слов уровня есть картинки, показываются только слова с картинками. Слова не повторяются, пока не пройдены все.
- Имена пишутся с заглавной буквы («Гарри»): карточки строчные, а в клеточке первая буква становится заглавной.

## Урок на этом движке

```
lessons/<урок>/
  lesson.json        — название, иконка, раздел, "uses": ["russian"] и команда сборки
  game.json          — история урока: названия уровней, окна, конфетти, стиль картинок
  theme.css          — необязательно: свои цвета поверх style.css движка
  data/words.txt     — слова: «частота<TAB>слово» (tools/words.py) или по слову в строке
  data/pictures.tsv  — к каким словам рисовать картинку и что на ней (уровень, слово, описание)
  images/, images.json — готовые картинки (tools/draw.py)
  README.md
```

Если `data/words.txt` нет, слова берутся из `data/pictures.tsv` — так удобнее, когда у каждого слова есть картинка.

`lesson.json`:

```json
{
  "title": "Волшебные слова",
  "description": "Читаем по слогам: …",
  "subject": "Чтение",
  "icon": "🪄",
  "uses": ["russian"],
  "build": "(cd ../read-game/game && npm ci) && node ../read-game/game/build_scripts/build.mjs .",
  "publish": "build"
}
```

`game.json`:

| Поле | Что это |
|---|---|
| `levels` | ровно три уровня: 2–3, 4 и 5+ карточек |
| `levels[].name`, `icon` | подпись и значок на кнопке уровня |
| `levels[].done` | окно, когда уровень пройден: `title`, `text`, `button` и необязательный `icon` (иначе — значок уровня). `{n}` в `text` заменяется на число собранных слов. Окно третьего уровня — финал игры, его кнопка начинает всё сначала |
| `doneIcon` | значок на кнопке пройденного уровня: 🏠 |
| `confetti` | значки, которые сыплются при верном ответе |
| `pictureStyle` | общий стиль картинок для `tools/draw.py` — чтобы все они были как из одной книжки |

`theme.css` переопределяет переменные из [game/style.css](game/style.css): `--sky`, `--main`, `--main-dark`, `--main-soft`, `--tile-border`, `--tile-shadow`, `--level-1` … `--level-3` (и `-soft`), `--grass`.

### Новый урок чтения

1. Скопируйте `lesson.json`, `game.json` и `theme.css` из [read-potter](../read-potter) и поменяйте.
2. Слова и картинки: заполните `data/pictures.tsv` (и `data/words.txt`, если слов больше, чем картинок).
3. Нарисуйте картинки и озвучьте новые слоги — см. ниже.
4. Строка в таблице уроков в корневом `README.md`.

## Картинки

```bash
python3 tools/draw.py read-potter --limit 3            # первые 3 — проверить стиль
python3 tools/draw.py read-potter                      # нарисовать всё, чего ещё нет
python3 tools/draw.py read-syllables --redo домик,лето # перерисовать отдельные
```

Урок — имя папки в `lessons/` или путь к ней. Что рисовать, задаёт `data/pictures.tsv` урока; общий стиль — `pictureStyle` в его `game.json`. Модель по умолчанию — `gpt-image-1-mini`, качество `low`: картинки уменьшаются до 256 px, большего не нужно. Нужны ключ `OPENAI_API_KEY` в `.env` в корне репозитория и macOS (`sips` уменьшает картинки).

Проверить на глаз — страница `tools/pictures.html`. Ей нужен сервер, запущенный из папки `lessons/`:

```bash
cd lessons && python3 -m http.server 8000
# http://localhost:8000/read-game/tools/pictures.html?lesson=read-potter
```

Клик помечает неудачные картинки, внизу появляется команда `draw.py … --redo …`.

## Слова из текста

Урок «Собери слово» берёт слова из сказки. Для другого текста:

```bash
python3 tools/words.py ../read-syllables/data/text1.txt -o ../read-syllables/data/words.txt
```

## Звуки

Новые слова часто приносят новые слоги. Звуки общие — они озвучиваются в [lessons/russian](../russian):

```bash
python3 ../russian/tools/syllables.py          # слоги всех уроков чтения
python3 ../russian/tools/speak.py --dry-run    # каких не хватает
python3 ../russian/tools/speak.py              # озвучить только недостающие
```

Слог без звука не ломает игру: он звучит по буквам.

## Собрать и посмотреть

```bash
(cd game && npm install)                          # один раз — TypeScript
node game/build_scripts/build.mjs ../read-potter  # → lessons/read-potter/build/
open ../read-potter/build/index.html              # открывается и двойным кликом, без сервера
```

Сборка ([game/build_scripts/build.mjs](game/build_scripts/build.mjs)) кладёт в `build/` урока страницу, код, стили, `theme.css`, картинки и `data.js` со словами, историей урока и списками звуков. Сами звуки она не копирует: игра берёт их из `lessons/russian/audio/`.

Разбивка на слоги написана дважды — `splitWord` в [game/src/main.ts](game/src/main.ts) и `split_word` в [../russian/tools/syllables.py](../russian/tools/syllables.py). Меняйте их вместе.
