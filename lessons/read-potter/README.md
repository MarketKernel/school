# 🪄 Волшебные слова

Игра для тех, кто учится читать по слогам, — как [🐷 Собери слово](../read-syllables), только слова из «Гарри Поттера»: Гарри, Добби, сова, палочка, Хогвартс, квиддич… Ребёнок слышит слово, собирает его из карточек-слогов и букв и проходит путь до Хогвартса:

| Уровень | Слова | Примеры |
|---|---|---|
| 🪄 Косой переулок | из 2–3 карточек | Га-р-ри, со-ва, ме-т-ла |
| 🚂 Хогвартс-экспресс | из 4 карточек | па-ло-ч-ка, д-ра-ко-н, Ха-г-ри-д |
| 🏰 Хогвартс | из 5 карточек и больше | Хо-г-ва-р-т-с, к-ви-д-ди-ч, е-ди-но-ро-г |

Всего 73 слова, у каждого своя картинка. Имена пишутся с заглавной буквы: карточки строчные, а в клеточке первая буква становится заглавной.

Урок работает на общем движке [read-game](../read-game) — там описано, как устроена игра. Звуки букв и слогов — общие для всех уроков чтения, они лежат в [lessons/russian](../russian).

## Что где лежит

| Файл / папка | Что это |
|---|---|
| `lesson.json` | название, иконка, раздел на главной и команда сборки |
| `game.json` | уровни, тексты окон, конфетти и стиль картинок — поля описаны в [read-game/README.md](../read-game/README.md) |
| `theme.css` | волшебные цвета: фиолетовый вместо поросячьего розового |
| `data/pictures.tsv` | слова и что нарисовать к каждому (уровень, слово, описание). Отдельного `words.txt` нет: слова урока — это слова отсюда |
| `data/words_split.txt` | слова, разбитые на слоги, — пишет `russian/tools/syllables.py` |
| `images/`, `images.json` | **готовые картинки** к словам |

## Собрать и посмотреть

```bash
(cd ../read-game/game && npm install)               # один раз — TypeScript
node ../read-game/game/build_scripts/build.mjs .    # → build/
open build/index.html                               # открывается и двойным кликом, без сервера
```

## Добавить слово

1. Строка в `data/pictures.tsv`: уровень (1 — до 3 карточек, 2 — 4, 3 — 5 и больше), слово, что нарисовать. Персонажей описывайте по внешности, без имён: «мальчик в круглых очках со шрамом-молнией».
2. Нарисовать и озвучить — команды из папки урока:

   ```bash
   python3 ../read-game/tools/draw.py read-potter      # нарисует только новые картинки
   python3 ../russian/tools/syllables.py               # слоги всех уроков чтения
   python3 ../russian/tools/speak.py --dry-run         # каких слогов не хватает
   python3 ../russian/tools/speak.py                   # озвучить недостающие
   ```

3. Проверить картинки на глаз: `cd .. && python3 -m http.server 8000` → http://localhost:8000/read-game/tools/pictures.html?lesson=read-potter. Неудачные — `python3 ../read-game/tools/draw.py read-potter --redo Гарри,сова`.

Слоги, которых не было в «Собери слово», озвучены тем же голосом Olga Orlova: ба, су, фе, вя, ге, тё, фи, фо. Послушать их и при желании перезаписать своим голосом — в [lessons/russian](../russian/README.md#свой-голос).
