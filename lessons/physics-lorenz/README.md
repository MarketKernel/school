# 🦋 Бабочка Лоренца

Система Лоренца — самая простая модель воздуха, который греют снизу: три числа `x, y, z` меняются по правилам
`x' = σ(y − x)`, `y' = x(ρ − z) − y`, `z' = xy − βz` при σ = 10, ρ = 28, β = 8/3. 2400 точек стартуют на крошечном
радужном отрезке (длиной 0,01) и летят по этим правилам, у каждой — короткий светящийся хвостик. Несколько витков они
летят одной белой искоркой, потом искорка раздваивается, вытягивается в радужные ленты и за десяток секунд
расползается по обоим крыльям бабочки. За облаком бледно нарисована сама бабочка — один длинный путь.

- **Тянуть пальцем** — повернуть бабочку, щипок двумя пальцами или колёсико — приблизить.
- **Нажатие** (без протягивания) — новое облако вылетает из ближайшего места бабочки.
- **✨ Облако / 🦋 Линия** — тысячи точек или одна точка с длинным следом, которая рисует бабочку целиком.
- **🔥 Нагрев** — число ρ от 10 до 40. Ниже ~24,7 хаос выключается: точки сбегаются в две спокойные точки.
- 🔄 — запустить ещё раз, ⏸ (или пробел) — пауза. В углу — сколько секунд прошло.

Что увидеть:

- Точки, которые стартовали ближе, чем на сотую долю, через несколько витков оказываются на разных крыльях.
- При слабом нагреве облако закручивается спиралью и останавливается в одной точке — хаоса нет.

Метод: метод Рунге — Кутты 4-го порядка с шагом 0,004 (0,8 единицы времени Лоренца в секунду). Каждая точка хранит 12
последних положений для хвостика; хвостики пересчитываются через поворот камеры и рисуются с аддитивным смешиванием
40 цветовыми группами и тремя полосами яркости. Код — [lorenz.ts](../physics/game/src/lorenz.ts).

Урок работает на общем движке [physics](../physics). Здесь только настройки:

| Файл | Что это |
|---|---|
| `lesson.json` | название, иконка, раздел на главной и команда сборки |
| `scene.json` | какая сцена (`lorenz`), строчка-загадка и текст карточки «Что тут происходит?» |

## Собрать и посмотреть

```bash
node ../physics/game/build_scripts/build.mjs .      # → build/
open build/index.html                               # открывается и двойным кликом, без сервера
```
