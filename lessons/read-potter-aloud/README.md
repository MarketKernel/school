# 🎤 Прочитай вслух

Ребёнок видит слово из «Гарри Поттера», уже разбитое на слоги («к · ры · са», «Га · р · ри»), и читает его вслух. Браузер распознаёт речь, под словом пишет, что услышал, и, если слово совпало, ставит звёздочку ⭐.

Картинки и кнопки «послушать» нет специально: иначе слово можно угадать по картинке или просто повторить, а надо прочитать.

Те же 73 слова, что в [🪄 Волшебных словах](../read-potter), и те же уровни по длине слова: 🪄 Косой переулок (2–3 части), 🚂 Хогвартс-экспресс (4), 🏰 Хогвартс (5 и больше).

## Как играть

- Нажать 🎤 «Читать» (или Enter) и прочитать слово. Можно по слогам, с паузами: браузер слушает, пока ребёнок не замолчит на 2,5 секунды (не дольше 10 секунд). Дочитал — можно не ждать и нажать кнопку ещё раз: на ней написано «Готово».
- Под словом — «Я услышал: «…»». Совпало — плашки становятся зелёными, +1 ⭐ и огонёк уровня. Не совпало — «Не совсем. Попробуй ещё раз!».
- За 25 прочитанных слов уровень пройден. Звёздочки копятся в браузере (`localStorage`), у каждого устройства свои.

## Распознавание речи

Через распознавание, встроенное в браузер (Web Speech API, язык `ru-RU`). Библиотеки и ключи не нужны.

- **Где работает:** Chrome и Edge (компьютер, Android), Safari (macOS, iOS). В Firefox распознавания нет.
- **Нужен интернет:** Chrome отправляет звук на серверы Google. Без сети и в Firefox появляется кнопка «👍 Получилось»: взрослый слушает и нажимает её сам.
- **Микрофон** браузер даёт только по `https://` (GitHub Pages подходит) или на `localhost`. При открытии двойным кликом распознавание может не заработать.
- **Проверка мягкая:** пробелы не важны (прочитанное по слогам «га ри» засчитывается за «Гарри»), «ё» = «е», в слове из 5 букв и длиннее прощается одна ошибочная буква («Хагрит»). Слово может стоять внутри фразы: «это сова». Но «кот» за «котёл» и «палка» за «палочку» не засчитываются.
- Распознаватель настроен на взрослую речь и сам «достраивает» слова, поэтому иногда ошибается в обе стороны. Если ребёнок прочитал верно, а браузер не понял, взрослый может нажать «Другое слово».

## Что где лежит

| Файл | Что это |
|---|---|
| `lesson.json` | название, иконка, раздел на главной и команда сборки. `uses` нет: во время игры урок ничего не берёт из общих папок |
| `game.json` | `"mode": "aloud"`, слова из `"potter"`, уровни, тексты окон и конфетти — поля описаны в [read-game/README.md](../read-game/README.md) |
| `theme.css` | цвета — те же, что у «Волшебных слов» |

Урок работает на общем движке [read-game](../read-game) (режим чтения вслух). Список слов сборка берёт из общей папки [lessons/potter](../potter) и кладёт в `data.js`; картинки и звуки этому уроку не нужны.

## Собрать и посмотреть

```bash
(cd ../read-game/game && npm install)               # один раз — TypeScript
node ../read-game/game/build_scripts/build.mjs .    # → build/
```

Распознавание проверяйте через сервер, а не двойным кликом: `npm run serve` в корне репозитория → http://localhost:8090/read-potter-aloud/.
