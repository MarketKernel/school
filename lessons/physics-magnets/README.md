# 🧲 Магнитное поле

Полосовые магниты (N — красный, S — синий) и невидимое поле вокруг них, которое можно увидеть тремя способами:

- **✨ Опилки** — тысячи светящихся железных опилок поворачиваются вдоль поля и ярче горят там, где оно сильнее, как настоящие опилки на бумаге. Когда магнит двигается, они поворачиваются следом с лёгким запаздыванием.
- **🧭 Компасы** — сетка компасов: стрелки пружинисто поворачиваются, проскакивают и успокаиваются; красный (северный) конец смотрит вдоль поля.
- **🌈 Линии** — цветные бегунки вылетают из северных полюсов, бегут вдоль поля и ныряют в южные, оставляя гаснущие следы — силовые линии.

Управление:

- **Перетаскивание** магнита — передвинуть его; **нажатие** на магнит — повернуть на 45° (с пружинкой); **круглая ручка ↻** рядом с магнитом — крутить как угодно; второй палец, пока первый держит магнит, тоже поворачивает его; колёсико мыши над магнитом — поворот.
- **+ Магнит** — добавить магнит (до четырёх), 🔄 — начать сначала, ⏸ (или пробел) — пауза. Нажатие на пустое место встряхивает опилки и стрелки.

Что увидеть:

- Разные полюса рядом — линии перекидываются мостиком с одного магнита на другой. Одинаковые — линии разбегаются, а между магнитами остаётся тёмное место почти без поля.
- Поле сильнее всего у полюсов, а не в середине магнита.

Каждый магнит — пара магнитных зарядов у концов (модель Гильберта): +1 у северного полюса, −1 у южного, поле каждого B = q·r̂ / r², как у точечного заряда в пространстве (бумага с опилками лежит на магнитах, поэтому закон трёхмерный). Вдали это ровно поле диполя. Поля всех магнитов складываются. Опилки — «стрелки без головы» (угол по модулю π), которые плавно поворачиваются к полю; компасы — затухающие крутильные маятники θ'' = K·|B|·sin(θ_B − θ) − c·θ'; линии — шаги методом средней точки вдоль B̂. Код — [magnets.ts](../physics/game/src/magnets.ts).

Урок работает на общем движке [physics](../physics). Здесь только настройки:

| Файл | Что это |
