# 🌈 Тысяча маятников

Тысяча двойных маятников (две равные гирьки на двух равных палочках) висят на одном гвоздике и стартуют почти из одного положения: угол верхней палочки у первого и последнего маятника отличается всего на стотысячную долю радиана. Маятники раскрашены радугой и рисуются тонкими светящимися линиями, которые складываются: пока они лежат друг на друге, видно один белый маятник. Через несколько секунд он расплывается в радужный веер и взрывается хаосом.

- **Потянуть пальцем** — кончик маятника идёт за пальцем (так выбирается начальная поза), **отпустить** — стартует новая тысяча.
- **1 / 100 / 1000** — сколько маятников запускать.
- **✨ Следы** — гаснущие следы кончиков.
- 🔄 — запустить ещё раз из той же позы, ⏸ (или пробел) — пауза.
- В углу — сколько секунд прошло с запуска.

Что увидеть:

- Первые секунды маятники качаются как один. Потом белая линия становится радужным веером: разница выросла в тысячи раз.
- Если отпустить маятник низко (кончик под гвоздиком), хаоса почти нет — тысяча маятников долго качается дружно. Хаос просыпается, когда маятник поднят высоко.

Метод: точные уравнения движения двойного маятника (из лагранжиана) для углов от вертикали, метод Рунге — Кутты 4-го порядка с мелкими шагами (1/360 с). Длина палочки 0,5 м, g = 9,81 м/с². Маятники рисуются в 90 цветовых группах с аддитивным смешиванием и мягким свечением. Код — [pendulums.ts](../physics/game/src/pendulums.ts).

Урок работает на общем движке [physics](../physics). Здесь только настройки:

| Файл | Что это |
|---|---|
| `lesson.json` | название, иконка, раздел на главной и команда сборки |
| `scene.json` | какая сцена (`pendulums`), строчка-загадка и текст карточки «Что тут происходит?» |
