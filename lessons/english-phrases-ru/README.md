# 🎧 Переведи на русский

300 самых ходовых английских фраз для детей: «Hello!», «Can I have some water?», «It's my turn.». Диктор говорит фразу по-английски, ребёнок говорит её по-русски, браузер слушает и проверяет. Получилось — ⭐ +1.

## Как играть

- Нажать 🔊 «Послушай» (или пробел): прозвучит фраза, а сразу за ней включится микрофон — можно отвечать. Сама фраза написана на карточке.
- Ответить по-русски. Пока ребёнок говорит, под фразой видно, что услышал браузер. Договорил — можно не ждать и нажать 🎤 «Готово».
- Не знаешь — 💡 «Подсказка» (или клавиша `H`): на карточке появится перевод, и он прозвучит (если у перевода нет звука — его прочитает голос системы). Потом микрофон включится сам — повтори.
- После двух неудачных попыток кнопка подсказки начинает подмигивать.
- После первой фразы следующие звучат сами, как только нажата «Следующая фраза →».

Фразы разбиты на 12 тем («Привет и пока», «Вежливые слова», «За столом», «В школе», «Играем», «На улице»…), есть ещё «🎲 Вперемешку». Под темой видно, сколько фраз уже переведено **без подсказки**: с подсказкой звёздочка тоже даётся, но в прогресс темы фраза не идёт. Когда переведены все — тема пройдена. Сначала чаще попадаются фразы, которые ещё не получались. Очки и прогресс хранятся в браузере, отдельно от «Скажи фразу по-английски».

## Как проверяется перевод

Распознавание речи браузера (Web Speech API, `ru-RU`). Засчитывается любой из переводов в `../english-phrases/data/phrases.tsv`: «Как дела?», «Как ты?», «Как у тебя дела?» — всё подходит к «How are you?». Порядок слов, окончания («я рада» за «я рад») и маленькие слова прощаются, «не» — нет. Подробно — в [README общей папки](../english-phrases/README.md#как-проверяется-ответ).

- **Где работает:** Chrome и Edge (компьютер, Android), Safari (macOS, iOS). В Firefox распознавания нет.
- **Нужен интернет:** Chrome отправляет звук на серверы Google. Без сети и в Firefox появляется кнопка «👍 Получилось»: взрослый слушает и нажимает её сам.
- **Микрофон** браузер даёт только по `https://` (GitHub Pages подходит) или на `localhost`.
- Если ребёнок перевёл верно, а браузер не засчитал, — допишите этот перевод в `phrases.tsv` или нажмите «Другая фраза».

## Что где лежит

| Файл | Что это |
|---|---|
| `lesson.json` | название, иконка, раздел, команда сборки, `"uses": ["english-phrases"]` |
| `game.json` | `"mode": "to-russian"` |

Фразы, звуки и код игры — в общей папке [lessons/english-phrases](../english-phrases); там же написано, как добавить фразы и переозвучить их.

## Собрать и посмотреть

```bash
(cd ../english-phrases/game && npm install)                # один раз — TypeScript
node ../english-phrases/game/build_scripts/build.mjs .     # → build/
cd .. && python3 -m http.server 8000                       # → http://localhost:8000/english-phrases-ru/build/
```

Сервер нужен из папки `lessons/`, чтобы были доступны звуки из `lessons/english-phrases`. Микрофон работает на `localhost`; при открытии `build/index.html` двойным кликом распознавание может не заработать.
