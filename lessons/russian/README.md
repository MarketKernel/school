# 🔤 Русский: звуки букв и слогов

Общие материалы для уроков чтения. Это не урок, а папка со звуками, которые используют все уроки на движке [read-game](../read-game):

| Урок | Что делаем |
|---|---|
| [🐷 Собери слово](../read-syllables) | слова из сказки «Три поросёнка» |
| [🪄 Волшебные слова](../read-potter) | слова из «Гарри Поттера» |

Здесь лежат все 33 буквы, мягкие согласные («ть», «ль»…) и слоги всех уроков чтения, а также утилиты, которые их озвучивают и записывают своим голосом.

## Как уроки берут звуки

- Папку помечает файл [shared.json](shared.json), поэтому корневая сборка публикует её один раз как `_site/russian/`: только `audio/letters/`, `audio/soft/` и `audio/syllables/`. На главной она не показывается.
- Урок указывает её в своём `lesson.json` (`"uses": ["russian"]`). Service worker сохраняет её вместе с уроком, так что без интернета всё работает.
- Сборка урока кладёт в свой `data.js` только списки звуков (`audio/*.json`). Сами звуки **не копируются**: игра загружает их из `../russian/` на сайте или из `../../russian/` при локальной сборке (`lessons/<урок>/build/`).

Новый слог достаточно озвучить здесь один раз — он зазвучит во всех уроках.

## Что где лежит

| Файл / папка | Что это |
|---|---|
| `audio/` | **готовые звуки**: `letters/`, `soft/`, `syllables/` и списки `*.json` |
| `audio/recorded.json` | звуки, записанные своим голосом, — `speak.py --force` их не трогает |
| `data/syllables.txt` | слоги всех уроков чтения по частоте — их озвучивает `speak.py` |
| `tools/syllables.py` | разбор слов всех уроков чтения на слоги |
| `tools/speak.py` | озвучка слогов и букв (ElevenLabs или OpenAI) |
| `tools/record_server.py`, `record.html`, `myvoice.html` | запись звуков своим голосом |
| `tools/listen.html`, `compare.html` | прослушать и сравнить звуки |

Скрипты сами находят свои папки — запускать их можно откуда угодно. Ниже команды даны из этой папки.

## Слоги

Слог здесь — пара «согласная + гласная» (ма, ви, де). Остальное (одиночные гласные, согласные без гласной) в игре показывается отдельными буквами и звучит по буквам.

```bash
python3 tools/syllables.py      # слова всех уроков → data/syllables.txt и <урок>/data/words_split.txt
python3 tools/speak.py --dry-run    # каких звуков не хватает — без запросов
python3 tools/speak.py              # озвучить только недостающие
```

Уроки чтения скрипт находит сам — это уроки, у которых в `lesson.json` есть `"uses": ["russian"]`. Слова урока — его `data/words.txt` или, если такого файла нет, слова из `data/pictures.tsv`.

## Звуки

```bash
python3 tools/speak.py --dry-run           # что будет озвучено — без запросов
python3 tools/speak.py                     # озвучить всё, чего ещё нет
python3 tools/speak.py --redo сё,шо,ж      # переозвучить отдельные звуки
python3 tools/speak.py --normalize         # только громкость и тишина у готовых файлов
```

> ⚠️ **Не перегенерируйте звуки целиком без нужды.** Каждый звук подбирали на слух, многие записаны своим голосом. Новые слоги — просто `python3 tools/speak.py`: он озвучит только недостающие.

Ключи — в файле `.env` **в корне репозитория** (пример — [.env.example](../../.env.example)):

- `ELEVENLABS_API_KEY` — озвучка. Голос Olga Orlova взят из Voice Library, а такие голоса через API доступны только на платном тарифе (хватает Starter).
- `OPENAI_API_KEY` — озвучка с `--provider openai`.

`brew install lame` — выравнивание громкости и обрезка тишины. Без него файлы останутся как пришли из сервиса.

Что выбрано и почему:

- **Голос** — Olga Orlova (`d60rsXo2p0OwikDR5bS7`) из ElevenLabs Voice Library, модель **`eleven_flash_v2_5`**. Multilingual v2 на коротком тексте игнорирует `language_code` и читает по-английски («С.» → «Си»); Flash v2.5 держит русский.
- **Буквы читаются как звуки**, а не названия: к согласной дописывается «ъ» — «Бъ.», а не «бэ».
- Для букв **с, й, р, л, ё, э** и мягких **ть, ль, сь, нь, рь** текст и модель подобраны вручную — см. `ELEVENLABS_LETTER_OVERRIDES` и `ELEVENLABS_SOFT_OVERRIDES` в `tools/speak.py`.
- **Своим голосом** записаны все 33 буквы, все 15 мягких согласных и 23 слога (же, ле, ре, ве, пе, се, бе, ше, ви, ме, ти, де, ди, ке, зе, си, жу, лы, сё, ща, ще, щи, щё). Они отмечены в `audio/recorded.json`: `speak.py --force` их пропускает, переозвучить можно только явно через `--redo`.

## Свой голос

```bash
python3 tools/record_server.py       # http://localhost:8000/tools/myvoice.html
```

- **myvoice.html** — записать любой звук своим голосом. Записи ложатся в черновик `audio/My/` (копия рабочего набора), кнопка «Поставить в игру» переносит его в `audio/` и пересобирает все уроки чтения.
- **record.html** — записать дубль и, по желанию, перевести его в голос Olga (ElevenLabs Speech-to-Speech). Дубли копятся в `compare/recorded/`, кнопка «Поставить» кладёт выбранный в `audio/`.

`audio/My/` и `compare/` — черновики, в git не попадают. В репозитории — только итоговый `audio/`.

## Проверить на слух

Страницам нужен локальный сервер, запущенный из этой папки (они загружают списки через `fetch`):

```bash
python3 -m http.server 8000          # или python3 tools/record_server.py
# страницы — http://localhost:8000/tools/listen.html и т. д.
```

- **listen.html** — все звуки. Shift+клик или долгое нажатие помечает плохие, внизу появляется команда `speak.py --redo …`.
- **compare.html** — сравнить варианты одного звука и выбрать на слух. Варианты кладутся в `compare/` и перечисляются в `compare/variants.json`:

  ```json
  { "ть": [ { "n": 1, "text": "Ть.", "model": "Flash v2.5", "file": "variants/soft_t_1.mp3" } ] }
  ```

  Выбранный вариант переносится в `tools/speak.py` как override.
