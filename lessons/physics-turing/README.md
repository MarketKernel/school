# 🦓 Узоры Тьюринга

Реакция-диффузия Грея — Скотта: два вещества растекаются по пластинке и превращаются друг в друга, и из почти ровной смеси сами вырастают полоски, пятна, кораллы и делящиеся «клетки». Концентрация второго вещества показана мягким градиентом с объёмной подсветкой, будто узор выпуклый.

- **Палец (или мышь)** — рисует второе вещество, узор прорастает из линии; можно несколькими пальцами сразу.
- **🦓 Зебра** — полоски и лабиринты, **🐆 Леопард** — пятнышки, **🪸 Кораллы** — ветвистые кораллы, **🦠 Клетки** — пятна, которые делятся пополам, **🪱 Черви** — извилистые червячки.
- **🔄** — посеять новые зёрнышки, ⏸ (или пробел) — пауза.

Что увидеть:

- Узор растёт фронтом от каждого зёрнышка, а там, где два фронта встречаются, они не сливаются, а аккуратно стыкуются.
- В «Клетках» пятнышко вытягивается в гантельку и распадается на два.
- У каждого узора свой «шаг»: полоски и пятна одной ширины, сколько ни рисуй.

Уравнения `∂u/∂t = Du ∇²u − uv² + F(1 − u)`, `∂v/∂t = Dv ∇²v + uv² − (F + k)v` решаются на видеокарте: состояние `(u, v)` хранится в текстуре с дробными числами (f32, если видеокарта умеет в неё рисовать, иначе f16 — узоры растут и так), края склеены, каждый шаг — явный шаг Эйлера с пятиточечным лапласианом (`Du = 0.2097`, `Dv = 0.105`, шаг сетки и времени — 1), 24 шага за кадр, а в первую секунду — 90, чтобы узор появился сразу. Сетка — 230 клеточек по короткой стороне экрана. Пары `(F, k)` взяты с карт Пирсона и Мунафо. Код — [turing.ts](../physics/game/src/turing.ts).

Урок работает на общем движке [physics](../physics). Здесь только настройки:

| Файл | Что это |
|---|---|
| `lesson.json` | название, иконка, раздел на главной и команда сборки |
| `scene.json` | какая сцена (`turing`), строчка-загадка и текст карточки «Что тут происходит?» |

## Собрать и посмотреть

```bash
(cd ../physics/game && npm install)                 # один раз — TypeScript
node ../physics/game/build_scripts/build.mjs .      # → build/
open build/index.html                               # открывается и двойным кликом, без сервера
```

Добавьте `#f16` к адресу страницы, чтобы проверить, как узоры растут на видеокартах без f32.
