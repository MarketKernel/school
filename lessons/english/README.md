# 🇬🇧 Английский: слова, картинки и звуки

Общие материалы для английских уроков. Это не урок, а папка с файлами, которые используют несколько уроков: 300 первых английских слов для детей, к каждому картинка и произношение.

| Урок | Что делаем |
|---|---|
| [🗣️ Скажи по-английски](../english-words) | слушаем слово и повторяем вслух, браузер проверяет |
| [👂 Найди картинку](../english-pictures) | слушаем слово и выбираем одну из четырёх картинок |

## Как уроки берут файлы

- Папку помечает файл [shared.json](shared.json), поэтому корневая сборка публикует её один раз как `_site/english/`, только `audio/` и `images/`. На главной она не показывается.
- Урок указывает её в своём `lesson.json` (`"uses": ["english"]`). Service worker сохраняет её вместе с уроком, так что без интернета всё работает.
- Сборка урока читает список слов через [words.mjs](words.mjs) и кладёт в свой `data.js` только слова и имена файлов. Картинки и звуки **не копируются**: игра загружает их из `../english/` на сайте или из `../../../english/` при локальной сборке (`lessons/<урок>/game/build/`).

Новое слово, звук или картинку достаточно добавить здесь: при следующей сборке они появятся во всех английских уроках.

## Что где лежит

| Файл / папка | Что это |
|---|---|
| `data/topics.tsv` | темы: ключ, иконка, название |
| `data/words.tsv` | слова: тема, слово, перевод, что нарисовать, что ещё засчитать при распознавании речи (через запятую: «two» → «to, too») |
| `data/similar.tsv` | похожие картинки: из одной строки в «Найди картинку» одновременно попадает не больше одной (`mom`, `woman`…) |
| `audio/` | **готовые звуки**: `cat.mp3`, `ice-cream.mp3`… |
| `images/` | **готовые картинки**: `cat.jpg`, `ice-cream.jpg`… |
| `words.mjs` | чтение списков для сборки уроков |
| `tools/speak.py` | озвучка слов (ElevenLabs или OpenAI) |
| `tools/draw.py` | картинки к словам (OpenAI Images) |
| `tools/review.html` | посмотреть все картинки, послушать звуки, пометить неудачные |

Имя файла получается из слова: строчные буквы, всё лишнее заменяется на дефис («T-shirt» → `t-shirt`).

## Добавить или поменять слова

1. Поправьте `data/words.tsv`. Новая тема — строка в `data/topics.tsv`.
2. `python3 tools/draw.py` и `python3 tools/speak.py`: они сделают только то, чего ещё нет.
3. Проверьте результат в `tools/review.html`. Если новая картинка похожа на какую-то из старых, допишите их в `data/similar.tsv`.

## Звуки и картинки

Ключи берутся из `.env` в корне репозитория (пример — [.env.example](../../.env.example)):

- `ELEVENLABS_API_KEY` — озвучка;
- `OPENAI_API_KEY` — картинки (и озвучка с `--provider openai`).

Нужны `lame` (`brew install lame`) — выравнивание громкости — и macOS (`sips` уменьшает картинки). Команды даны из этой папки, но скрипты можно запускать откуда угодно.

```bash
python3 tools/speak.py --dry-run          # что будет озвучено — без запросов
python3 tools/speak.py --limit 5          # первые 5 — послушать голос
python3 tools/speak.py                    # озвучить всё, чего нет
python3 tools/speak.py --redo cat,dog     # переозвучить отдельные слова
python3 tools/speak.py --voices           # какие голоса ElevenLabs доступны по ключу

python3 tools/draw.py --dry-run           # что будет нарисовано
python3 tools/draw.py --limit 5           # первые 5 — посмотреть стиль
python3 tools/draw.py --only numbers      # только одну тему
python3 tools/draw.py --redo cat,dog      # перерисовать отдельные слова
```

- **Звук:** ElevenLabs, голос Sarah (американский английский), модель `eleven_multilingual_v2`. Настройки начинаются с `EN_`, чтобы не путаться с русским голосом «Собери слово»: `EN_TTS_PROVIDER`, `EN_ELEVENLABS_VOICE`, `EN_ELEVENLABS_MODEL`, `EN_OPENAI_TTS_VOICE`.
- **Картинки:** `gpt-image-1-mini`, качество `low`. Меньше 1024×1024 эта модель не рисует, до 320 px картинка уменьшается уже после генерации.

Что выяснилось при генерации:

- Больше ~7 предметов модель пересчитывает неправильно. Поэтому на 8–12 нарисована одна крупная цифра, без предметов для счёта.
- Признак рисуйте так, чтобы его не спутали с предметом: «огромный мяч рядом с ребёнком», а не «огромный слон» (иначе ребёнок скажет «elephant»). Эмоции — крупным лицом.
- Фильтр OpenAI отклонил «босая детская ступня». Части тела лучше описывать без слов «босой» и «детский».

Проверка — с сервером из этой папки:

```bash
python3 -m http.server 8000      # → http://localhost:8000/tools/review.html
```
