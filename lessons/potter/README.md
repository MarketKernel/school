# ⚡ Гарри Поттер: слова и картинки

Общие материалы для уроков чтения со словами из «Гарри Поттера». Это не урок, а папка, которую используют несколько уроков:

| Урок | Что делаем |
|---|---|
| [🪄 Волшебные слова](../read-potter) | собираем слово из карточек-слогов |
| [🎤 Прочитай вслух](../read-potter-aloud) | читаем слово вслух, браузер проверяет |

73 слова — Гарри, Добби, сова, палочка, Хогвартс, квиддич… — и к каждому картинка.

## Как уроки берут слова и картинки

- Папку помечает файл [shared.json](shared.json), поэтому корневая сборка публикует её один раз как `_site/potter/`, только `images/`. На главной она не показывается.
- Урок указывает её дважды: в `lesson.json` (`"uses": ["russian", "potter"]`) и в `game.json` (`"words": "potter"`). Сборка движка [read-game](../read-game) берёт отсюда слова и список картинок, а сами картинки **не копирует**: игра загружает их из `../potter/` на сайте или из `../../potter/` при локальной сборке.
- Звуки слогов — общие для всех уроков чтения, они в [lessons/russian](../russian).

Новое слово достаточно добавить здесь: оно появится в обоих уроках.

## Что где лежит

| Файл / папка | Что это |
|---|---|
| `shared.json` | что публиковать и `pictureStyle` — общий стиль картинок для `draw.py` |
| `data/pictures.tsv` | слова и что нарисовать к каждому: уровень (1 — до 3 карточек, 2 — 4, 3 — 5 и больше), слово, описание |
| `data/words_split.txt` | слова, разбитые на слоги, — пишет `russian/tools/syllables.py` |
| `images/`, `images.json` | **готовые картинки** к словам |

## Добавить слово

1. Строка в `data/pictures.tsv`. Персонажей описывайте по внешности, без имён: «мальчик в круглых очках со шрамом-молнией».
2. Нарисовать и озвучить — команды из этой папки:

   ```bash
   python3 ../read-game/tools/draw.py potter      # нарисует только новые картинки
   python3 ../russian/tools/syllables.py          # слоги всех уроков чтения
   python3 ../russian/tools/speak.py --dry-run    # каких слогов не хватает
   python3 ../russian/tools/speak.py              # озвучить недостающие
   ```

3. Проверить картинки на глаз: `cd .. && python3 -m http.server 8000` → http://localhost:8000/read-game/tools/pictures.html?lesson=potter. Неудачные — `python3 ../read-game/tools/draw.py potter --redo Гарри,сова`.

Картинки рисует `gpt-image-1-mini` (качество `low`), нужен ключ `OPENAI_API_KEY` в `.env` в корне репозитория.
