# 🏖️ Песочная куча

Абелева песочная куча Бака — Тана — Визенфельда. Песчинки падают в середину, клетка с четырьмя песчинками осыпается — отдаёт по одной каждому из четырёх соседей, лавины бегут по куче, а сама куча вырастает в симметричную фрактальную мандалу. Цвета клеток: тёмно-фиолетовый — 0 песчинок, голубой — 1, розовый — 2, золотой — 3; клетки, которые только что осыпались, вспыхивают.

- **Сначала** в середину сыплется струйка, всё быстрее и быстрее, пока куча не займёт заметную часть экрана.
- **Нажатие (и удержание) пальцем или мышью** — в этом месте сыплется песок, чем дольше держишь — тем быстрее; можно несколькими пальцами, можно вести палец.
- **⛰️ Высыпать гору** — сразу 65 536 (2¹⁶) песчинок в середину: видно, как огромная куча расплывается и раскладывается в узор.
- **🔄** — убрать весь песок, ⏸ (или пробел) — пауза. Справа вверху — сколько песчинок лежит на столе (упавшие с края пропадают).

Что увидеть:

- Узор квадратно-симметричен, хотя песок сыплется в одну точку, а внутри у него повторяются одни и те же треугольники и полоски разного размера.
- Две кучи рядом не смешиваются как попало: на границе вырастают новые ровные узоры.
- Иногда одна песчинка вызывает огромную лавину — вспышка пробегает по всей куче.

Сетка — около 300 клеток по короткой стороне экрана (целое число пикселей экрана на клетку), рисуется через `ImageData`. Неустойчивые клетки стоят в очереди; клетка с `h` песчинками отдаёт каждому соседу сразу `⌊h/4⌋` — по абелеву свойству результат от этого не меняется, а большая гора считается в тысячи раз быстрее. На осыпания отводится 7 мс за кадр, поэтому гора растёт на глазах несколько секунд. Код — [sandpile.ts](../physics/game/src/sandpile.ts).

Урок работает на общем движке [physics](../physics). Здесь только настройки:

| Файл | Что это |
|---|---|
| `lesson.json` | название, иконка, раздел на главной и команда сборки |
| `scene.json` | какая сцена (`sandpile`), строчка-загадка и текст карточки «Что тут происходит?» |

## Собрать и посмотреть

```bash
(cd ../physics/game && npm install)                 # один раз — TypeScript
node ../physics/game/build_scripts/build.mjs .      # → build/
open build/index.html                               # открывается и двойным кликом, без сервера
```
