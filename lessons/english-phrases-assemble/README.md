# 🧩 Собери фразу

Диктор говорит английскую фразу, а ребёнок собирает её из карточек со словами — по порядку. Фразы те же, что в [🎧 Переведи на русский](../english-phrases-ru), кроме 9 фраз из одного слова («Help!», «Look!»): там нечего собирать. Остаётся 291 фраза.

## Как играть

- Фраза звучит сама (в самый первый раз нажмите 🔊 «Послушай» или пробел). Перевод написан на карточке, чтобы был понятен смысл.
- Нажимать на слова внизу по порядку — они встают в строку. Слово из строки можно убрать обратно нажатием (или `Backspace`).
- Строка заполнилась: если всё верно — ⭐ +1, и фраза звучит ещё раз. Если нет — слова не на своих местах становятся красными: их надо убрать и поставить правильно.
- 💡 «Подсказка» (`H`): оставляет верное начало, убирает остальное и ставит следующее нужное слово. После двух неудачных попыток кнопка начинает подмигивать.
- В короткой фразе есть лишние карточки: две — во фразе из 2–3 слов, одна — из 4–5. Лишние слова берутся из фраз той же темы.
- Первое слово пишется со строчной буквы, чтобы заглавная не подсказывала начало. Исключения — «I» и имена («Anna», «Monday»).
- Клавиши: `1`–`9` — карточка по номеру, пробел — послушать, Enter — следующая фраза.

Темы те же 12 плюс «🎲 Вперемешку». Под темой видно, сколько фраз собрано **без подсказки**. Очки и прогресс хранятся в браузере, отдельно от других уроков.

## Что где лежит

| Файл | Что это |
|---|---|
| `lesson.json` | название, иконка, раздел, команда сборки, `"uses": ["english-phrases"]` |
| `game.json` | `"mode": "assemble"` |

Фразы, звуки и код игры — в общей папке [lessons/english-phrases](../english-phrases). Микрофон этому уроку не нужен.

## Собрать и посмотреть

```bash
(cd ../english-phrases/game && npm install)                # один раз — TypeScript
node ../english-phrases/game/build_scripts/build.mjs .     # → build/
cd .. && python3 -m http.server 8000                       # → http://localhost:8000/english-phrases-assemble/build/
```
