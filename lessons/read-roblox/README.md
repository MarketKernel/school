# 🎮 Секреты Роблокса

Урок чтения для фанатов Роблокса: ребёнок читает вслух короткую фразу про Роблокс, браузер слушает, а в награду голос рассказывает что-нибудь интересное — секрет, рецепт прохождения, совет, как сделать свою игру, или загадку.

## Как играть

- На экране — фраза из 5–15 слов. Нажми 🎤 «Читать» и прочитай её вслух; каждое услышанное слово становится зелёным. Нажми «Готово» (или просто замолчи) — игра проверит.
- Прочитал — +1 ⭐, конфетти и награда: звучит текст на 15–50 слов из той же пары, под фразой появляется его текст. 🔊 — послушать ещё раз, «Дальше →» — следующая фраза.
- Не получилось — неуслышанные слова подчёркнуты волной, «Ещё раз» — попробовать снова. «Другая фраза» откладывает фразу на потом.
- Три уровня по длине фразы: «Нуб» 🟨 — 5–7 слов, «Профи» 😎 — 8–9, «Легенда» 👑 — 10 и больше. Уровень пройден, когда прочитаны все его фразы.
- Без распознавания речи (Firefox, нет интернета, нет микрофона) взрослый слушает и нажимает «👍 Получилось».

Игра собирается общим движком [read-game](../read-game) в режиме `sentence`: `lesson.json` + `game.json` (уровни, окна, конфетти) + `theme.css` (цвета кубиков). Звуки наград сборка копирует из `audio/`. Как проверяется прочитанное — в [README движка](../read-game/README.md#четыре-режима).

```sh
npm run build                                                   # весь сайт
node lessons/read-game/game/build_scripts/build.mjs lessons/read-roblox && open lessons/read-roblox/build/index.html
```

## Материалы

| Файл | Что это |
|---|---|
| `data/pairs.json` | 100 пар: фраза для чтения и награда к ней, подобранные по теме (фраза про Дорс — секрет про Дорс) |
| `audio/<id>.mp3` | озвученные награды (делает `tools/voice.py`, ElevenLabs); фразы для чтения не озвучиваются — ребёнок читает их сам |

Поля пары:

| Поле | Что это |
|---|---|
| `id` | номер пары и имя звука: `001` … `100` |
| `read` | фраза для чтения, 5–15 слов |
| `reward` | награда, 15–50 слов: её текст показывается, а звук играет |
| `tts` | необязательно: как произносить награду, если текст для экрана не годится для голоса («/e dance» → «слэш и дэнс»), или с `+` перед ударной гласной («Р+облокс»), если голос ошибся в ударении |

Тексты написаны по памяти о Роблоксе — то, что может устареть (число игроков, рекорды), стоит иногда проверять. Новую пару можно дописать в конец `pairs.json` со следующим `id` и озвучить.

## Озвучка — `tools/voice.py`

Озвучивает `tts` (или `reward`) каждой пары. Голос — Николай из библиотеки ElevenLabs (`ROBLOX_ELEVENLABS_VOICE=3EuKHIEZbSzrHGNmdYsx` в `.env`; без него — Ольга Орлова, голос остальных уроков чтения), модель `eleven_multilingual_v2` (`ROBLOX_ELEVENLABS_MODEL`). Ключ — `ELEVENLABS_API_KEY` из `.env` в корне репозитория. Громкость выравнивается так же, как у слогов (нужен `lame`: `brew install lame`).

```sh
python3 lessons/read-roblox/tools/voice.py --dry-run          # что будет озвучено, без запросов
python3 lessons/read-roblox/tools/voice.py --limit 2          # первые две — проверить голос
python3 lessons/read-roblox/tools/voice.py                    # всё, чего ещё нет
python3 lessons/read-roblox/tools/voice.py --redo 004,037     # переозвучить эти пары
python3 lessons/read-roblox/tools/voice.py --force            # переозвучить всё (~19 тысяч символов)
python3 lessons/read-roblox/tools/voice.py --redo 004 --voices 3EuKHIEZbSzrHGNmdYsx,d60rsXo2p0OwikDR5bS7
    # одна награда разными голосами → compare/<id голоса>/ (не в git), audio/ не трогается
python3 lessons/read-roblox/tools/voice.py --redo 004 --compare eleven_flash_v2_5,eleven_multilingual_v2
    # то же разными моделями → compare/<модель>/
```

Озвучка платная (кредиты ElevenLabs): сначала `--dry-run` и `--limit`. Голос из библиотеки ElevenLabs сам добавляется в аккаунт при первом запросе.
