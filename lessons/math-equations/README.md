# 🔎 Уравнения

Тренажёр «найди x»: вместо первого или второго числа стоит x, нужно быстро понять, чему он равен. Все четыре действия вперемешку:

```
x + 4 = 7      9 − x = 5      3 × x = 21      x ÷ 8 = 7
```

Это тот же [«Всё вперемешку»](../math-mix), только неизвестно не что получится, а одно из чисел. Каждый пример даёт два уравнения: `3 + 4 = 7` → `x + 4 = 7` и `3 + x = 7`.

Уравнения, где x может быть любым числом, пропускаются: `x × 0 = 0`, `0 × x = 0`, `0 ÷ x = 0`. У каждого оставшегося ровно один ответ.

## Уровни

Уровень N — это уровни N уроков [сложения](../math-addition), [вычитания](../math-subtraction), [умножения](../math-multiplication) и [деления](../math-division) вместе.

| Уровень | Что в нём | Уравнений всего |
|---|---|---|
| 1. лёгкий | сложение и вычитание до 5, умножение и деление на 0 и 1 | 179 |
| 2. средний | сложение и вычитание до 10, таблицы на 2 и 5 | 284 |
| 3. трудный | через десяток, таблицы на 3 и 4 | 164 |
| 4. самый трудный | сложение и вычитание до 18, таблицы на 6–9 | 124 |

Раунд — **20 случайных уравнений, по 5 каждого действия**. На ответ — 5 секунд. Лучший результат уровня запоминается звёздами.

Неверные ответы похожи на типичные ошибки: переписанное число из уравнения или обратное действие наоборот. Например, для `x + 4 = 7` это 11 (сложил вместо вычитания), для `x ÷ 8 = 7` — 15.

Урок работает на общем движке [math-drill](../math-drill) — там описано, как устроена игра. Здесь только настройки:

| Файл | Что это |
|---|---|
| `lesson.json` | название, иконка, раздел на главной и команда сборки |
| `drill.json` | какие уроки смешать (`mix`), `"unknown": true` — уравнения, секунды на пример, примеров в раунде (`count`), названия уровней — поля описаны в [math-drill/README.md](../math-drill/README.md) |

## Собрать и посмотреть

```bash
(cd ../math-drill/game && npm install)              # один раз — TypeScript
node ../math-drill/game/build_scripts/build.mjs .   # → build/, в конце — сколько уравнений в каждом уровне
open build/index.html                               # открывается и двойным кликом, без сервера
```
